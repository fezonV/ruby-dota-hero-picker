# Архив проверки авторизации — 23 октября 2026

Ниже зафиксированы результаты конкретного запуска. Это не отчёт о текущем
состоянии всех проверок после последующих изменений проекта.

Проверка выполнена на локальном PostgreSQL, с которым Rails соединяется
через `/tmp/.s.PGSQL.5432`. Docker-контейнеры PostgreSQL не публикуют порт на хост.

- До изменений: `bin/rails test` — 21 тест, 110 проверок, без ошибок.
- После добавления UI Kit и проверок повторного запроса/выхода:
  `bin/rails test` — 23 теста, 126 проверок, без ошибок.
- `bin/rails zeitwerk:check` — успешно.
- `bundle exec rubocop --cache false` — 36 файлов, нарушений нет.
- `bundle exec brakeman --quiet --no-pager` — ошибок и предупреждений нет.

Тесты покрывают регистрацию, валидацию пользователя, нормализацию email,
верный/неверный пароль, сохранение сессии между запросами, выход и отказ
гостю в доступе к главной, аккаунту и UI Kit. В коде подтверждены bcrypt,
strong parameters регистрации, reset_session при входе и выходе,
очистка паролей перед Turbo-кэшированием.

В браузере проверены вход отдельным локальным тестовым аккаунтом
`ui-kit-check@example.test`, переход с главной в UI Kit, поиск по роли,
пустой поиск и выбор карточки. Этот аккаунт создан только в development.
Чужие драфты через HTTP не проверялись: маршрутов драфтов нет. Владение
через связь `User#drafts` отдельно проверено модельным тестом.

# Aegis Draft

Rails-приложение для составления драфтов в Dota 2 и ранжирования лучших
доступных героев с понятными рекомендациями, основанными на статистике.

Сейчас завершена первая итерация проекта — регистрация и авторизация
пользователей. Советник по драфтам будет добавлен в следующих итерациях.

## Что уже работает

- регистрация по email и паролю с подтверждением пароля;
- безопасное хранение паролей с помощью `bcrypt`;
- вход и выход из аккаунта;
- защищённая главная страница, доступная только после входа;
- нормализация email и локализованные основные ошибки валидации;
- единый тёмный дизайн входа, регистрации и аккаунта с голубым акцентом;
- фоновый аегис из отдельных символов, которые меняются при движении курсора;
- модельные и интеграционные тесты аутентификации.

## Технологии

- Ruby 4.0.7;
- Ruby on Rails 8.1.4;
- PostgreSQL, проверено на версии 18.3;
- Hotwire: Turbo и Stimulus;
- Minitest;
- RuboCop и Brakeman.

## Требования

- Ruby 4.0.7
- Bundler
- PostgreSQL

Rails и остальные зависимости устанавливаются командой `bundle install`.

## Локальный запуск

```sh
git clone https://github.com/fezonV/ruby-dota-hero-picker.git
cd ruby-dota-hero-picker
bundle install
bin/rails db:prepare
bin/rails server
```

После запуска приложение доступно по адресу `http://localhost:3000`. Гость попадает на экран входа; регистрация доступна по ссылке в шапке. После входа открывается защищённая главная.

Выбранное визуальное направление и поведение фона описаны в [DESIGN.md](DESIGN.md). Галерея первоначальных вариантов остаётся по адресу `/design-lab/index.html`.

Вместо отдельных команд подготовки можно использовать:

```sh
bin/setup
```

Скрипт установит зависимости, подготовит базу данных и запустит сервер.

## Проверки

```sh
bin/rails test
bin/rails zeitwerk:check
bundle exec rubocop --cache false
bundle exec brakeman --quiet --no-pager
```

## Ближайшие этапы

1. Подключить модели драфта к защищённому редактору и списку своих драфтов.
2. Показать рекомендации с объяснениями и добавлением героя через интерфейс.
3. Пройти сквозной сценарий сохранения и повторного открытия.
4. В дальнейшем подключить статистику матчей из внешнего источника.

## UI Kit

После входа откройте `/ui-kit` или кнопку «Открыть UI Kit» на главной.
Это живая галерея общих CSS-компонентов: палитра, типографика, кнопки,
поля, состояния ошибок, карточки героев, слоты команды и образец рекомендации.
Поиск и выбор героя работают только внутри демонстрации и не сохраняются.
Страница требует авторизации. Пользовательские экраны драфта ещё не подключены к моделям.

## Модели драфта (пока без пользовательских экранов)

Добавлены `Hero`, `Draft`, `DraftPick`, связи с пользователем, ограничения базы
и тесты. Для загрузки учебного набора из 12 героев:

```sh
bin/rails db:migrate
bin/rails db:seed
```

Повторный запуск seeds обновляет записи по имени. Характеристики 0–3
назначены вручную; это учебные значения, не статистика Dota 2.
`Draft#recommendations` ранжирует свободных героев по потребностям команды
и возвращает объяснения. Формула описана в `docs/guide-for-defense.md`.
Редактор, HTTP-доступ к драфтам и сохранение через интерфейс — следующий этап.

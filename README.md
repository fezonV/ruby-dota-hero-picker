# Aegis Draft

Aegis Draft — учебный помощник для драфтов Dota 2. Пользователь регистрируется,
входит, создаёт собственный драфт, выбирает союзников и противников и получает
объяснимые рекомендации. Каждый выбор сразу сохраняется в PostgreSQL; состав
можно открыть после выхода и нового входа. Статистика матчей не подключена.

## Что уже работает

- регистрация по email и паролю с подтверждением пароля;
- безопасное хранение паролей с помощью `bcrypt`;
- вход и выход из аккаунта;
- защищённая главная страница, доступная только после входа;
- нормализация email и локализованные основные ошибки валидации;
- единый тёмный дизайн входа, регистрации и аккаунта с голубым акцентом;
- фоновый аегис из отдельных символов, которые меняются при движении курсора;
- защищённый UI Kit с демонстрационными карточками, слотами и поиском;
- модели `Hero`, `Draft`, `DraftPick`, учебные seeds и расчёт `Draft#recommendations`;
- список собственных драфтов, создание и редактор двух команд по пять героев;
- поиск по имени и роли, удаление и применение настоящих рекомендаций;
- тесты аккаунта, моделей, полного HTTP-сценария и браузерные Capybara/Selenium-тесты.

UI Kit не читает учебный каталог из базы и не вызывает расчёт рекомендаций.
Выбор карточки в нём не сохраняется. Рабочий сценарий находится в разделе «Мои драфты».

## Локальный запуск

```sh
git clone https://github.com/fezonV/ruby-dota-hero-picker.git
cd ruby-dota-hero-picker
bundle install
bin/rails db:prepare
bin/rails server
```

После запуска приложение доступно по адресу `http://localhost:3000`. Гость с `/`
попадает на экран входа. После регистрации нужно войти отдельно; затем
открывается защищённая главная с основной кнопкой «Мои драфты».

Выбранное визуальное направление и поведение фона описаны в [DESIGN.md](DESIGN.md).
В текущей рабочей копии исходная галерея доступна по адресу
`/design-lab/index.html`; каталог `public/design-lab/` исключён из Git и
отсутствует после обычного клонирования репозитория.

Вместо отдельных команд подготовки можно использовать:

```sh
bin/setup
```

Скрипт проверит зависимости, подготовит базу данных и запустит сервер через
`bin/dev`. Для подготовки без запуска сервера используйте `bin/setup --skip-server`.

Чтобы загрузить или обновить учебные записи героев, выполните:

```sh
bin/rails db:seed
```

Seeds содержат 12 героев с вручную заданными характеристиками от 0 до 3.
Повторный запуск обновляет записи по имени. Это не статистика Dota 2.

Официальные портреты всех 12 героев лежат в `public/heroes/` и показываются
в каталоге, составах, рекомендациях и UI Kit. Это исходные PNG Valve 256×144,
уменьшенные в интерфейсе с сохранением пропорций; внешний API для их показа
не нужен. Ссылки на источники — в [public/heroes/README.md](public/heroes/README.md).

## UI Kit

После входа откройте `/ui-kit` или кнопку «Открыть UI Kit» на главной.
Это живая галерея общих CSS-компонентов: палитра, типографика, кнопки,
поля, состояния ошибок, карточки героев, слоты команды и образец рекомендации.
Поиск и выбор героя работают только внутри демонстрации и не сохраняются.
Страница требует авторизации. Карточки и пример рекомендации заданы прямо в
представлении. Рабочий редактор отдельно использует записи `Hero` из базы.

## Драфты и рекомендации

`Hero` хранит имя, роль и четыре оценки: поддержку, контроль, урон и стойкость.
`Draft` принадлежит пользователю; `DraftPick` задаёт героя, команду и позицию.
Миграция ограничивает допустимые значения, повтор героя и занятое место.
`Draft#recommendations(limit: 5)` исключает выбранных героев, оценивает
оставшихся по дефицитам союзной команды и стойкости противника и возвращает
балл с объяснениями. Это учебная эвристика, не прогноз победы.

Подробные правила и схема описаны в [руководстве для защиты](docs/guide-for-defense.md).
Для объяснения последней доработки подготовлен [пошаговый гайд к защите](docs/draft-defense-guide.md).
Все маршруты драфтов защищены авторизацией. Контроллеры ищут драфт через
`current_user.drafts`, а выбор — через найденный драфт. Чужой или отсутствующий
ресурс возвращает 404. Название ограничено 100 символами. Сервер принимает
только название либо `hero_id` и `team`; владелец и позиция задаются сервером.
`Draft#add_pick` блокирует строку драфта (`with_lock`) на время поиска свободного
места и сохранения. При ошибке ответ — 422, после сохранения — перенаправление 303.
Схема базы и её ограничения сохранены.

### Как пройти сценарий

1. Зарегистрируйся и отдельно войди.
2. Открой «Мои драфты» → «Создать драфт», введи название.
3. В каталоге выбери «Моя команда» или «Противники», найди героя по имени или роли
   и нажми на его карточку. Он займёт первое свободное место. Сторона сохраняется.
4. Прочитай балл и объяснения рекомендации. «Добавить в мою команду» всегда
   добавляет союзника, даже если каталог переключён на противников.
5. Собери пять союзников — появится «Команда собрана». Удали одного: место
   освободится, рекомендации вернутся. После действий видно «Состав сохранён».
6. Вернись в список драфтов, выйди, снова войди и открой сохранённый состав.

Браузерные тесты используют Chrome/Chromium в headless-режиме и Selenium
Manager для драйвера (первый запуск может потребовать сеть). Если браузер установлен
не в стандартном месте, передай путь через `CHROME_BIN`. Тестовые 12 героев
берутся из fixtures, без seeds и внешних сервисов. Для сохранения снимков страниц:
`VISUAL_QA=1 bin/rails test:system`; PNG появятся в `tmp/visual-qa/`.
